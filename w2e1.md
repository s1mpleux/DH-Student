## Challenge 1 — Generate Data

**Goal:** Write a Python script that generates a CSV file containing two columns of random numbers.

### Design Discussion (with AI)

Generating data means constructing a controlled synthetic dataset. This experiment generates 10,000 rows of floating-point values (`x`, `y`), each drawn uniformly from `[0, 1]`. A uniform distribution has a known theoretical mean of 0.5 and variance of 1/12 ≈ 0.0833, which gives us ground-truth reference values to validate the processing pipeline later.

### Implementation — `generate_data.py`

```python
#!/usr/bin/env python3
"""
generate_data.py
Generate a CSV file containing uniformly distributed random data.
Usage: python generate_data.py [--rows N] [--output FILE]
"""

import csv
import random
import argparse


def generate_uniform_data(rows: int, output_path: str) -> None:
    """
    Generate uniformly distributed random data and write it to a CSV file.

    Args:
        rows        -- number of rows to generate
        output_path -- path to the output file
    """
    with open(output_path, 'w', newline='', encoding='utf-8') as f:
        writer = csv.writer(f)
        writer.writerow(['x', 'y'])
        for _ in range(rows):
            writer.writerow([random.uniform(0, 1), random.uniform(0, 1)])
    print(f"Generated {rows} rows → {output_path}")


if __name__ == '__main__':
    parser = argparse.ArgumentParser(description='Generate uniformly distributed random dataset')
    parser.add_argument('--rows',   type=int, default=10000, help='Number of rows (default: 10000)')
    parser.add_argument('--output', type=str, default='data.csv', help='Output file path (default: data.csv)')
    args = parser.parse_args()
    generate_uniform_data(args.rows, args.output)
```

### CLI Usage

```bash
# Generate default 10,000 rows
python generate_data.py

# Custom row count and output file
python generate_data.py --rows 5000 --output my_data.csv
```

### Expected Output

```
Generated 10000 rows → data.csv
```

## Challenge 2 — Process the Data (IPO Pattern)

**Goal:** Implement simple statistical processing functions that read and process the generated CSV from the command line.

### IPO Design

| Phase | Content |
|-------|---------|
| **Input** | CSV file path (from CLI argument) |
| **Process** | Compute mean, standard deviation, max, and min for columns `x` and `y` |
| **Output** | Print statistical results to the console |

### Implementation — `process_data.py`

```python
#!/usr/bin/env python3
"""
process_data.py
Read data from a CSV file and compute basic statistical features.
Usage: python process_data.py --input data.csv
"""

import csv
import argparse
import math
from typing import List, Dict


def read_csv(filepath: str) -> List[Dict[str, float]]:
    """
    Input phase: read data from CSV.
    Returns a list of dicts, one per row.
    """
    records = []
    with open(filepath, 'r', encoding='utf-8') as f:
        reader = csv.DictReader(f)
        for row in reader:
            try:
                records.append({'x': float(row['x']), 'y': float(row['y'])})
            except (ValueError, KeyError):
                pass  # skip invalid rows
    return records


def process_statistics(records: List[Dict[str, float]]) -> Dict[str, Dict[str, float]]:
    """
    Process phase: compute basic statistics for each column.

    Statistics:
    - mean:  measure of central tendency
    - std:   spread of the data
    - min / max: range of the data
    - count: number of valid data points
    """
    results = {}
    for col in ['x', 'y']:
        values = [r[col] for r in records]
        n = len(values)
        if n == 0:
            continue
        mean = sum(values) / n
        variance = sum((v - mean) ** 2 for v in values) / n
        std = math.sqrt(variance)
        results[col] = {
            'count': n,
            'mean':  round(mean, 6),
            'std':   round(std, 6),
            'min':   round(min(values), 6),
            'max':   round(max(values), 6),
        }
    return results


def output_results(stats: Dict[str, Dict[str, float]]) -> None:
    """Output phase: print results to the console."""
    print("\n=== Statistical Results ===")
    for col, s in stats.items():
        print(f"\nColumn: {col}")
        for k, v in s.items():
            print(f"  {k:10s}: {v}")


if __name__ == '__main__':
    parser = argparse.ArgumentParser(description='Process CSV data and output statistics')
    parser.add_argument('--input', type=str, required=True, help='Input CSV file path')
    args = parser.parse_args()

    data  = read_csv(args.input)
    stats = process_statistics(data)
    output_results(stats)
```

### CLI Usage

```bash
python process_data.py --input data.csv
```

  count     : 10000

  min       : 0.000021

## Challenge 3 — OOP Refactor (Backend–Model–Process)

**Goal:** Refactor the scripts into an object-oriented architecture that separates the file backend, data model, and processing logic.

### Architecture Discussion (with AI)

The Backend–Model–Process pattern separates three concerns:

- **Backend** — handles data I/O, hiding the details of the underlying file format
- **Model** — encapsulates the internal data representation
- **Process** — accepts a backend object and a processing function, driving the entire data flow

The key advantage is **pluggability**: different analyses can be performed simply by swapping the processing function, without touching the I/O or main-loop code.

### Implementation — `pipeline_oop.py`

```python
#!/usr/bin/env python3
"""
pipeline_oop.py
Backend-Model-Process OOP architecture.
Usage: python pipeline_oop.py --input data.csv --process mean
"""

import csv
import math
import argparse
from typing import Iterator, Callable, Dict, Any


class CSVBackend:
    """
    File-reading backend.
    Encapsulates CSV file reading logic and yields data points as dicts.
    """

    def __init__(self, filepath: str):
        self.filepath = filepath

    def read(self) -> Iterator[Dict[str, str]]:
        """Yield one data dict per row."""
        with open(self.filepath, 'r', encoding='utf-8') as f:
            reader = csv.DictReader(f)
            for row in reader:
                yield row


class DataPipeline:
    """
    Data processing pipeline (Model + Process).
    Accepts a backend object and a processing function, drives the whole flow.
    """

    def __init__(self, backend: CSVBackend, process_func: Callable):
        self.backend      = backend
        self.process_func = process_func

    def run(self) -> Any:
        """Read all data from the backend, pass to the processing function."""
        records = list(self.backend.read())
        return self.process_func(records)


# ============ Pluggable processing functions ============

def process_mean(records):
    """Compute the mean of columns x and y."""
    results = {}
    for col in ['x', 'y']:
        values = [float(r[col]) for r in records if r.get(col)]
        if values:
            results[col] = {'mean': round(sum(values) / len(values), 6), 'n': len(values)}
    return results


def process_summary(records):
    """Compute a full statistical summary."""
    results = {}
    for col in ['x', 'y']:
        values = [float(r[col]) for r in records if r.get(col)]
        if not values:
            continue
        n    = len(values)
        mean = sum(values) / n
        std  = math.sqrt(sum((v - mean) ** 2 for v in values) / n)
        results[col] = {
            'count': n,
            'mean':  round(mean, 6),
            'std':   round(std, 6),
            'min':   round(min(values), 6),
            'max':   round(max(values), 6),
        }
    return results


PROCESS_REGISTRY = {
    'mean':    process_mean,
    'summary': process_summary,
}


if __name__ == '__main__':
    parser = argparse.ArgumentParser(description='OOP data processing pipeline')
    parser.add_argument('--input',   required=True, help='Input CSV file')
    parser.add_argument('--process', choices=list(PROCESS_REGISTRY.keys()),
                        default='summary', help='Processing function to use')
    args = parser.parse_args()

    backend  = CSVBackend(args.input)
    pipeline = DataPipeline(backend, PROCESS_REGISTRY[args.process])
    result   = pipeline.run()

    print(f"\n=== Result (function: {args.process}) ===")
    for col, stats in result.items():
        print(f"  {col}: {stats}")
```

### CLI Usage

```bash
# Full statistical summary
python pipeline_oop.py --input data.csv --process summary

# Mean only
python pipeline_oop.py --input data.csv --process mean
```

### Architecture Note on Efficiency

During the design discussion, it became apparent that the row-by-row `yield` approach specified in the exercise description is inefficient for aggregate statistics (mean, std, etc.), because those operations require access to all data points at once. The `run()` method therefore collects all records first and then passes the entire list to the processing function. This design trade-off is noted in the code comments.
